# Bank Management System

A console-based Bank Management System built in C++ featuring account operations, file handling, and transaction capabilities.

## Features

- **Account Management**: Check account status and access account details.
- **Deposit & Withdrawal**: Perform cash deposits and secure withdrawals with balance validation.
- **Balance Inquiry**: View real-time account balance.
- **Utility Bill Payments**: Pay electricity, water, and phone bills directly from the bank account.
- **File Handling**: Log and save account data/transactions using C++ file streams (`fstream`).

## Getting Started

### Prerequisites

- A C++ compiler (such as GCC/MinGW, Clang, or MSVC).

### Compilation & Execution

Using GCC / MinGW:
```bash
g++ bank.cpp -o bank.exe
./bank.exe
```
